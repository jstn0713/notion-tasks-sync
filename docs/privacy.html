개인정보처리방침 / Privacy Policy

최종 수정 / Last updated: 2026-11-25

1. 대상 / Who uses this app

notion-tasks-sync는 소유자 본인 한 명만 사용하는 개인용 프로그램이며, 다른 사용자에게 제공하지 않습니다.
notion-tasks-sync is a personal tool used only by its owner and is not offered to anyone else.

2. 접근하는 구글 데이터 / Google data accessed

구글 Tasks 권한(https://www.googleapis.com/auth/tasks)으로 소유자의 할 일 목록에서 제목, 메모, 날짜, 완료 여부, 하위 할 일 관계를 읽고 수정합니다.
Using the Google Tasks scope, the app reads and updates the owner's task titles, notes, due dates, completion status and subtask relations.

3. 사용 목적 / How the data is used

오직 소유자의 Notion 데이터베이스와 내용을 맞추는 데에만 사용합니다. 광고, 분석, 판매, AI 학습 등 다른 목적으로 사용하지 않습니다.
The data is used only to keep the owner's Notion database in sync. It is never used for advertising, analytics, sale, or training AI models.

4. 저장과 공유 / Storage and sharing

할 일 내용은 별도 서버에 저장하지 않으며, 구글 Tasks와 소유자의 Notion 사이에서만 전달됩니다. 어떤 항목끼리 짝인지 기억하기 위한 항목 번호(ID)만 소유자의 Notion에 저장합니다. 제3자와 공유하지 않습니다.
Task content is not stored on any separate server; it is transferred only between Google Tasks and the owner's Notion. Only item IDs used to pair tasks are stored, in the owner's own Notion. No data is shared with third parties.

이 앱의 구글 사용자 데이터 사용은 Google API Services User Data Policy의 Limited Use 요구사항을 따릅니다.
The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. 삭제 / Deletion

소유자는 언제든 구글 계정 설정의 '타사 앱 액세스'에서 권한을 취소하고, 이 저장소를 삭제해 모든 동작을 멈출 수 있습니다.
The owner can revoke access at any time from Google Account → Third-party access and stop the app by deleting this repository.
